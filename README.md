# 股市白話通

用白話告訴你「股票今天為什麼漲跌」。主要靠 **AdMob 廣告**賺錢：看廣告賺點數，用點數解鎖報告；查股票時偶爾跳插頁廣告。

- 本機打開：雙擊 `APP專案\start.cmd`，網址 http://localhost:5189 （加 `?dev` 會出現開發者工具：切換假廣告模式、加點數、清資料）
- 手動更新今天的資料：雙擊 `更新資料.cmd`（Groq 金鑰放在 `pipeline\.env`，一行 `GROQ_API_KEY=...`，已加進 .gitignore 不會上傳）
- 測試：`node test.js`（65 項）

## 🔥 熱力圖（v0.3，免費）

底部選單第 2 個（原本的「查詢」移到頂部 🔍）。

- **範圍**：全市場（照產業分區，點產業標題放大）、單一產業（右上「選產業…」）、⭐ 自選、12 個概念股群組（AI 伺服器、散熱、CoWoS、矽光子、IC 設計、PCB／CCL、記憶體、重電、機器人、航運、金控、熱門 ETF；在 `core.js` 的 `GROUPS`，人工整理）
- **大小**：市值／成交值／平均（每檔一樣大，台積電不會蓋掉其他股票）。全市場只畫前 400 檔（平均模式 300 檔）
- **顏色**：漲跌幅（±6% 最深，漲停跌停另外加深）／外資買賣超金額
- **點方塊**：跳小卡（價格、市值、成交值、三大法人、加自選），再按「看個股」才進個股頁（避免誤觸插頁廣告）
- 首頁「族群強弱」的產業標籤點了直接跳到該產業的熱力圖
- 產業改用**證交所／櫃買的官方產業代碼**（FinMind 的分類有重複的大類），市值＝官方已發行股數 × 收盤價，每週更新一次股數

## 畫面和互動（v0.2）

做法參考兩支抖音影片：「先做功能、再定風格、分階段改、保留可退回的版本」和「讓 App 更精緻的 6 個交互」。v0.1 備份在 `備份\v0.1\`。

- **固定的風格規則**（`index.html` 的 v0.2 區塊）：深藍玻璃卡片（上亮下暗、頂部高光、柔和陰影）、背景淡淡的看盤格線、頂部跟著大盤紅綠微微發光、按下會縮一點、載入用骨架、列表依序浮上來
- **6 個交互**（`fx.js`）：
  1. 完成回饋按鈕：解鎖時按鈕縮成圓、畫出打勾、噴金幣粒子，內容依序滑出
  2. 勾選連動：點數數字滾動、加點時噴金幣、點數頁的「今日廣告」進度環
  3. 疊卡展開：深度報告各項分析疊成一疊，點開依序攤開，收起整齊疊回（魔鬼代言人風險清單一直顯示）
  4. 吸附卡＋畫線：首頁加權（近 3 個月走勢線）、櫃買、漲跌家數、三大法人卡片左右滑會吸附；走勢線一段一段畫出來
  5. 慣性尺規：盲測改成拖動尺規猜漲跌幅（-30%～+30%），有慣性、吸附刻度、拉過頭彈回；差 3% 以內是「神準」+1 點
  6. 圓形擴散轉場：點底部選單時，新頁面從手指按的位置擴散開
- 手機有震動回饋（Android 瀏覽器；包成 App 後裝 Haptics 外掛也會用）
- 系統設定「減少動態效果」時全部關掉

## 點數和廣告規則（數字都在 `core.js` 的 `ECON`）

- 新朋友送 10 點；每日簽到 +1；看完一支獎勵廣告 +3（每天最多 10 支）
- 同一份報告當天看過可以免費重看
- 中途關掉廣告不給點；**廣告播不出來**時直接免費解鎖（每天最多 3 次），不讓使用者卡住
- 插頁廣告：查股票時每 3 次跳 1 次、至少隔 2 分鐘、新手前 3 次不跳、剛看完獎勵廣告 1 分鐘內不跳
- 網頁版播的是假廣告；包成 App 後自動走 AdMob（`ads.js`，寫法和萬劍誅魔、許願圓夢池一樣）

## 資料從哪來（全部免費）

| 資料 | 來源 | 誰去抓 |
|---|---|---|
| 上市行情、指數、漲跌家數、三大法人 | 證交所網站 MI_INDEX、T86 | 每日資料程式 |
| 上櫃行情、三大法人、櫃買指數 | 櫃買中心 OpenAPI | 每日資料程式 |
| 產業分類 | FinMind TaiwanStockInfo（一週更新一次） | 每日資料程式 |
| 個股歷史股價、新聞 | FinMind（免註冊每小時 300 次） | 每日資料程式＋App |
| 法人歷史、融資、月營收、本益比 | FinMind | App（每個使用者用自己的額度） |
| AI 解說 | Groq 免費額度（每天約 1,000 次） | 每日資料程式 |

FinMind 新聞一次只能抓一天、不能帶 `end_date`；論壇貼文（股市爆料同學會）和「鉅額成交」公告會被濾掉。

## 怎麼運作

```
每個交易日 17:30、20:30（GitHub Actions 自動跑，免費）
  pipeline/build.js
    → 抓上市＋上櫃全部行情、法人 → data/market.json（約 160KB）
    → 挑成交值前 30＋漲幅前 20＋跌幅前 20 → 抓新聞和 45 天股價 → 寫解說 → data/explain.json
    → 存回儲存庫 → GitHub Pages 網站自動更新
App（網頁版或 iPhone App）
    → 讀 data/*.json；深度報告、盲測、走勢圖直接向 FinMind 抓
```

AI 的規則（`core.js` 的 `aiPrompt`、`aiOk`）：只能用給它的資料、不能猜、不能給買賣建議；回答太短、太長、有「建議買進／目標價」字眼、簡體字太多，就改用規則版。

## 上線前要做的事

1. **Groq 金鑰**（✅ 2026-11-03 已申請，本機在 `pipeline\.env`；上 GitHub 後還要貼進 Secrets）：到 https://console.groq.com 用 Google 登入 → API Keys → Create。把金鑰放到 GitHub 儲存庫的 Settings → Secrets → Actions，名稱 `GROQ_API_KEY`。沒有金鑰也能跑，只是解說是規則版。
2. （可選）FinMind 註冊拿 token，放 `FINMIND_TOKEN`，每小時次數從 300 變 600。

4. **AdMob**：建 App「股市白話通」＋獎勵廣告＋插頁廣告，編號填進 `ads.js` 的 `PROD`，`ADS_TEST` 改 `false`。
5. 包成 iPhone App（Capacitor，照 `筆記本\iPhone App 打包與上架流程.md`）。

## 要注意

- **法規**：在台灣，針對個股給買賣建議要有投顧執照。App 只描述資料，不寫「建議買進」「目標價」；每頁都有免責聲明；「偏多／偏空」只是把資料分類。上架說明也不要寫「報明牌」「穩賺」。
- **Apple 審查**：金融類 App 可能會被問資料來源，回覆時附上證交所、櫃買中心、FinMind。
- 點數現在存在使用者手機裡（localStorage），會改的人可以作弊。等使用者變多再改成雲端（Firebase）。
- GitHub Pages 要**公開儲存庫**才免費；資料都是公開資料，沒有問題，但不要把金鑰寫進程式。
